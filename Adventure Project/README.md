# Adventure Game

An object-oriented text adventure game in Python.

## Files
- `AdvGame.py` — game loop
- `AdvItem.py` — items
- `AdvRoom.py` — rooms
- `Adventure.py` — entry point
- `tokenscanner.py` — input parsing
- `CrowtherRooms.txt`, `CrowtherItems.txt`, `CrowtherSynonyms.txt` — the classic Crowther adventure data
- `SmallRooms.txt`, `SmallItems.txt`, `SmallSynonyms.txt`, `TinyRooms.txt` — smaller maps
- `TeachingMachine/` — the Teaching Machine code used for Milestone 0

## How to run
```bash
python3 Adventure.py
```
