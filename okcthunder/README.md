# OKC Thunder Shot Prediction

A shot prediction model built for an application for an internship with the Oklahoma City Thunder.

I was tasked to build a shot prediction model off of two large datasets, one training and one testing.

## Files
- `project_code.Rmd` — the model code (R)
- `project_writeup.pdf` — the full writeup, with the model and results
- `submission.csv` — predictions
- `testing.csv.gz` — test data

The training.csv dataset was too large to import into GitHub.

Please check out `project_writeup.pdf` for more information.
