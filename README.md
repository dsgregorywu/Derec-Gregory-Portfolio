Trie-based chord predictor for beginner composers. Stores chord progressions from a Kaggle dataset in a trie, then suggests next chords ranked by frequency.

Oregon Pathfinder — Python
Route-finding over Oregon cities with A*, Dijkstra, and Greedy Best-First Search, with a comparison of path, distance, vertices explored, and runtime.
- Repo: [dsgregorywu/Oregon-Pathfinder](https://github.com/dsgregorywu/Oregon-Pathfinder)
- Example: Portland → Ashland, A* finds PORTLAND → SALEM → EUGENE → ROSEBURG → MEDFORD → ASHLAND, 283 miles, in 0.0011s.
